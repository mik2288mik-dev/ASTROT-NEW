# Твой Гороскоп — static marketing site

Быстрый статический сайт без Next.js, npm и сборки.

## Как открыть локально

Откройте `website/index.html` двойным кликом. Все основные стили и страницы работают через относительные ссылки.

## Структура

- `index.html` — русская главная;
- `en/index.html` — английская главная;
- `privacy.html` — политика конфиденциальности RU/EN;
- `terms.html` — условия использования RU/EN;
- `delete-account.html` — публичная инструкция удаления аккаунта RU/EN;
- `support.html` — поддержка RU/EN;
- `404.html` — страница ошибки;
- `assets/styles.css` — общий дизайн;
- `assets/favicon.svg` — иконка сайта.

## Перед публикацией обязательно

1. Заменить все значения в квадратных скобках: оператор, страна, адрес, email поддержки.
2. Проверить фактический список поставщиков, стран хранения, сроков хранения и платёжную схему.
3. После юридической проверки заменить `noindex,nofollow` на `index,follow` в `privacy.html` и `terms.html`.
4. Добавить реальные ссылки RuStore / Google Play после публикации приложения.
5. После выбора домена добавить canonical URL, Open Graph image и `sitemap.xml` с абсолютными адресами.

## Ограничения

Сайт не использует фальшивые отзывы, оценки, количество пользователей и не показывает несуществующие кнопки магазинов.
