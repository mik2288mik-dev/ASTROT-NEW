1. Никаких UI-заглушек вместо бизнес-логики.
2. Никаких placeholder text report / fake analysis / mock interpretation.
3. Любая функция, связанная с натальной картой, должна иметь:
   - расчетный слой
   - слой интерпретации
   - слой хранения
   - слой отображения
4. Full Report и Pro Report — это разные продукты, а не один и тот же текст в двух экранах.
5. Full Report = понятный язык для обычного пользователя.
6. Pro Report = профессиональный астрологический режим с домами, аспектами, терминами, орбисами.
7. UI не должен генерировать астрологический смысл сам.
8. Все тексты отчетов должны приходить из backend / server logic.
9. Никаких заглушек там, где должна быть реальная функция.
