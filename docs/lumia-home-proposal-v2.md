## Home «Сегодня» — порядок блоков

1. **Шапка** — avatar → Settings, приветствие + имя, мотивация дня (1 строка)
2. **2×2 метрики** — % + подпись «пик дня …»
3. **Гороскоп teaser** → вкладка Гороскоп (article reader)
4. **Натальная teaser** → вкладка Карта
5. **Союз compact** — 2 знака, локальные % → вкладка Союз
6. **Спроси Lumia** — горизонтальные pill-вопросы → вкладка Спроси

**Не показываем:** число дня, цвет дня, lucky fluff.
