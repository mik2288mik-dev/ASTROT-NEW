# Задача: переписать личный «Сегодня» без выдуманных сцен и псевдоязыка

## Цель

Полностью заменить текущую генерацию личного дня на систему, где сервер передаёт модели только рассчитанные астрологические факты, а GPT-4.1 кратко объясняет их обычным русским языком.

Модель не придумывает разговоры, покупки, задачи, конфликты, людей и события. Она не даёт советы автоматически и не заменяет прогноз психологией.

## Зафиксированный продуктовый состав

Постоянные темы:

1. Твой день
2. Любовь
3. Работа и дела
4. Деньги
5. Настроение и силы
6. Общение
7. Удача

Дополнительно каждый день сервер выбирает 2–3 темы по реальной силе расчётных факторов. Допустимый каталог дополнительных тем должен быть контролируемым и типизированным.

## Обязательная архитектура ответа модели

Каждая тема возвращает:

```ts
type DailyReading = {
  card: string;
  reading: string;
  astrology: {
    explanation: string;
    factors: Array<{
      factor: string;
      orb: number | null;
      status: 'applying' | 'separating' | 'exact' | 'unknown';
      period: string | null;
      meaning: string;
    }>;
  };
};
```

Весь дневной пакет:

```ts
type PersonalTodayPackage = {
  date: string;
  your_day: DailyReading;
  love: DailyReading;
  work: DailyReading;
  money: DailyReading;
  mood_energy: DailyReading;
  communication: DailyReading;
  luck: DailyReading;
  dynamic: Array<{
    key: DynamicTodayTopicKey;
    title: string;
    reading: DailyReading;
  }>;
  meta: {
    model: string;
    prompt_version: string;
    calculation_version: string | null;
    generated_at: string;
  };
};
```

## Системный промпт

Использовать единый голос приложения, но добавить/зафиксировать следующие правила:

- сразу отвечай на вопрос темы;
- объясняй только переданные расчёты;
- затем показывай астрологическое основание;
- не придумывай жизненные обстоятельства;
- не подменяй прогноз психологическим портретом;
- не давай рекомендацию, если она не следует прямо из расчёта и не нужна для ответа;
- не увеличивай текст ради поля;
- никаких фраз: «день неоднозначный», «фон спокойнее», «темп снижается», «день требует ясности», «лучше закончить начатое», «главная задержка», «сделаешь больше обычного» и аналогов;
- обычный современный русский язык, без эзотерики, коучинга и псевдопсихологии.

## Task-промпт личного дня

Промпт должен:

1. Получить подготовленный сервером пакет фактов по каждой теме.
2. Не перераспределять аспекты между темами самостоятельно.
3. Не создавать искусственные hero-заголовки и hooks.
4. Не требовать «узнаваемые сцены».
5. Не требовать советы и действия.
6. Разрешать астрологическое объяснение в отдельном поле.
7. Использовать только максимальные ограничения длины, без минимума.
8. Остановиться сразу после полного ответа.
9. Если влияния по теме недостаточно — сказать это кратко и без наполнения пустотой.

## Что удалить из текущей реализации

- правило добавлять сообщения, покупки, сроки, обещания, счета, просьбы, приглашения и разговоры;
- валидатор, считающий количество бытовых сцен;
- `ABSTRACT_DAILY_TEXT` в текущем значении;
- запрет на планеты/аспекты в отдельном объяснительном поле;
- hero_title/hero_hook как обязательный AI-контент;
- старые темы goals/family/friendship как обязательные;
- старые `DAILY_FALLBACK_VARIANTS` с выдуманными ситуациями;
- минимальные длины и `TEXT_TOO_SHORT`, когда поле содержит законченный короткий ответ;
- советы как обязательную часть любой темы.

## Серверная подготовка данных

До вызова GPT сервер должен:

- рассчитать натальную карту;
- получить транзиты на дату;
- рассчитать транзит→натал аспекты;
- учитывать точность орбиса, applying/separating и период действия, когда доступны;
- распределить факторы по темам;
- выбрать 2–3 динамические темы по силе факторов;
- не отправлять одной теме факторы, уже использованные как главный источник другой темы, если это создаёт повтор.

Нужен типизированный `DailyTopicEvidence`:

```ts
type DailyTopicEvidence = {
  primary: CalculatedAstroFactor[];
  supporting: CalculatedAstroFactor[];
  conflicting: CalculatedAstroFactor[];
  confidence: 'high' | 'medium' | 'low';
};
```

## Ограничения текста

Только потолки:

- `card`: до 280 символов;
- `reading`: до 700 символов;
- `astrology.explanation`: до 500 символов;
- `factor.meaning`: до 240 символов;
- факторов в теме: максимум 4 наиболее важных.

Это не целевой объём. Одно или два предложения допустимы и предпочтительны, когда вопрос уже закрыт.

## Валидация

Жёстко отклонять:

- выдуманные события/обстоятельства;
- советы без расчётного основания;
- психологические диагнозы и портрет вместо прогноза;
- запрещённый псевдоязык;
- повтор одной мысли в нескольких темах;
- астрологические факторы, отсутствующие во входном пакете;
- превышение потолка длины;
- неверную JSON-структуру.

Не отклонять короткий законченный ответ только из-за длины.

## Fallback

Не показывать неперсонализированный выдуманный прогноз.

При ошибке генерации:

- вернуть состояние `unavailable`/`generating`;
- сохранить диагностический код;
- повторить генерацию один раз;
- UI показывает короткое нейтральное сообщение о временной недоступности, а не гороскоп-заглушку.

## Кэш

- поднять версию prompt/cache;
- старые дневные пакеты не считать совместимыми;
- новый ключ должен учитывать дату, chart calculation version, prompt version, voice version и модель;
- не удалять кэш натальной карты, недели, месяца и других продуктов;
- инвалидировать только старый personal Today.

## UI

Главный экран:

- большая карточка «Твой день»;
- сетка: Любовь, Работа и дела, Деньги, Настроение и силы, Общение, Удача;
- ниже горизонтальная лента 2–3 дополнительных тем;
- в карточке показывать `card`;
- внутри темы сначала `reading`;
- ниже раскрытие «Почему такой прогноз» → `astrology.explanation`;
- ниже «Показать расчёт» → список `factors`;
- никаких AI-generated CTA, hero-заголовков и hooks.

## Монетизация

Не менять оплату в этой задаче, но сохранить возможность:

- «Твой день» полностью free;
- одна постоянная тема free по текущей продуктовой логике;
- остальные полные reading и расчёты доступны Premium;
- короткие `card` видны всем.

## Модель

Использовать единый resolver `getUnifiedContentModel()`; модель по умолчанию GPT-4.1. Не создавать отдельный слот для «Сегодня».

## Тесты

Добавить/обновить тесты:

1. prompt не содержит требования бытовых сцен;
2. prompt разрешает отдельное астрологическое объяснение;
3. контракт содержит ровно 7 постоянных тем;
4. dynamic содержит 2–3 элемента;
5. короткий законченный ответ проходит валидацию;
6. запрещённые фразы отклоняются;
7. выдуманные scene-маркеры не требуются;
8. факторы ответа входят во входной evidence;
9. старый кэш personal Today несовместим;
10. UI корректно отображает reading/explanation/factors;
11. `npm test`, typecheck и build проходят.

## Definition of Done

- старый daily canvas больше не используется пользовательским экраном;
- новый пакет строится из расчётных evidence по темам;
- GPT-4.1 только объясняет эти evidence;
- 7 постоянных + 2–3 динамические темы;
- астрологическое объяснение доступно отдельно;
- нет выдуманных сцен, обязательных советов и психологической воды;
- старые фолбэки не могут попасть пользователю;
- тесты, typecheck и production build зелёные;
- в итоговом отчёте перечислены изменённые файлы, новая схема, миграция кэша и оставшиеся риски.
