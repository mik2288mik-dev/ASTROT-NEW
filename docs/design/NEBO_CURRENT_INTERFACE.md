# Действующий интерфейс NEBO

С 13 сентября 2026 года используем только действующий белый интерфейс приложения: штатную шапку AppTopBar, текущую типографику и отступы, белый фон и нижнюю навигацию LumiaBottomTabBar.

Администраторский экспериментальный дизайн отменён. Его экраны, стили, переключатель, клиентское хранение настроек и отдельный предпросмотр удалены. Не возвращать этот вариант и не добавлять переключение дизайна. Старый параметр ссылки `design` не влияет на отображение.

В натальном разделе остаются вкладки «Карта», «Разбор», «Спросить о себе». «Матрица судьбы» — отдельная функция. Во вкладке «Карта» сохраняется новый интерактивный круг, нижнее окно выбранного объекта и отдельный экран «Почему такой вывод». Последний объясняет выбранную планету, дом, аспект или точку и не открывает общий «Разбор».

Источник карты — существующие сохранённые расчёты пользователя. Удаление визуального эксперимента не меняет расчёты, серверные генерации, API и записи пользователей. Старый серверный контракт настроек дизайна сохранён для совместимости; интерфейс его больше не вызывает и не использует.

Локальный UI Preview открывается через `?uiPreview=1` на сервере разработки с `NEXT_PUBLIC_UI_PREVIEW=1`. Он показывает действующий интерфейс на локальных примерах и блокирует сетевые обращения к прикладным API. Примеры не являются пользовательскими production-данными.

На текущем этапе проверяем изменения локально. Не собирать APK, не запускать релиз, не публиковать изменения, не менять production ENV, БД или существующие записи пользователей.
