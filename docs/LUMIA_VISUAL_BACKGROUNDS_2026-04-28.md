# Lumia Visual Backgrounds — 2026-04-28

## Решение

Добавлена отдельная визуальная система фонов для экранов, которые должны ощущаться живыми и персональными:

- Натальная интерпретация меняет фон по смыслу раздела: портрет, формула, светила, сильные стороны, рост, отношения, работа/деньги и daily.
- Синастрия меняет фон по `compatibilityScore`: 10 мягких состояний от напряженного теплого тона до спокойного зелено-золотого.
- Гороскопные фоны по 12 знакам уже лежат в `public/horoscope-zodiac/` и остаются отдельным контуром.

## Ассеты

- `public/natal-backgrounds/*.webp` — 8 полноэкранных WebP-фонов.
- `public/synastry-backgrounds/bond-00.webp` … `bond-09.webp` — 10 WebP-фонов для score buckets.
- Все фоны 1080x1920, без текста внутри картинки, чтобы UI-тексты оставались HTML/CSS и не превращались в баннер.

## Логика

- Вся маршрутизация фонов собрана в `lib/visualBackgrounds.ts`.
- Public API и БД не меняются.
- Если score синастрии отсутствует, используется нейтральный фон `bond-05.webp`.

## Дизайн-правила

- Фон поддерживает текст, но не спорит с ним.
- Никаких агрессивных красных ошибок, тревожности или рекламного вида.
- Фон должен усиливать ощущение “Lumia понимает контекст”, а не быть декоративной заглушкой.
