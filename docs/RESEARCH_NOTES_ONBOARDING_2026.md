# Research notes — onboarding and pre-launch, 2026

These notes explain the product decisions without turning external trends into blind imitation.

## What current platform guidance supports

- Onboarding should be brief, enjoyable and optional.
- Interactive onboarding is stronger than a slideshow of instructions.
- Contextual tips should teach features at the moment they are used.
- Nonessential setup should be postponed.
- Users should experience product value before rating or purchase prompts.
- Important privacy/security choices should be configurable and explained clearly.
- Account creation requires clear account deletion paths and transparent data handling.

## What this means for «Твой Гороскоп»

1. Screens 1–2 explain value only.
2. Screen 3 makes a real choice instead of teaching fake gestures.
3. Birth data is requested only for the Personal path.
4. Zodiac users enter useful content immediately.
5. Personal calculation progress is real, not a decorative timer.
6. Premium is introduced after the user sees meaningful content.
7. Feature education after onboarding uses contextual tips inside Zodiac, Today, Natal and Compatibility.
8. Legal links appear before sensitive birth-data submission and remain available in Settings.

## Trends deliberately rejected

- long quiz funnels that exist mainly to delay a paywall;
- forced account creation before any value;
- ten-screen feature tours;
- fake progress screens;
- screenshots embedded inside onboarding screens;
- dark purple cosmic templates used only because the category is astrology;
- fear-based subscription copy;
- collecting gender, notifications or location permissions before a feature actually needs them;
- generic AI-personalization claims without real chart/period inputs.

## Trend applied carefully

Personalization is valuable only when it changes the actual experience. The onboarding asks one meaningful product question — Personal or Zodiac — and then collects only the data required for that path. It does not add a large personality quiz merely because such funnels are fashionable in subscription apps.
