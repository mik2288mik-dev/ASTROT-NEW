# Android Release Plan

This is a lightweight release note for the future native wrapper of "Your Horoscope".

## Current State

The active product is a Next.js Telegram Mini App and web app. Native Android work is not part of the current MVP cleanup.

## Future Native Work

- Wrap the existing web app only after the MVP routes and billing rules are stable.
- Add store-compliant auth and billing separately from Telegram Stars.
- Re-check privacy policy, account deletion, age rating, Data Safety, analytics, and push notification consent before any store submission.

## Guardrail

Do not add native-only screens, dead settings, placeholder CTAs, or store-specific billing branches to the active web MVP before a real native implementation begins.
