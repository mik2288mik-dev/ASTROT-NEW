# Проверка ответов о двух людях

2026-09-08. Реальные запросы к gpt-5.6-luna через тот же `generatePairFutureText`, который использует API. Данные примеров вымышленные. Аккаунты и PostgreSQL-кеш проверкой не изменялись.

Последний результат: три сценария получили готовые ответы и прошли проверки текста. Полные входные данные и ответы — в `live-samples.json`.

- Друзья, Рыбы + Телец: «Как нам проще договориться?»
- Семья, взрослый 1989-03-14 и ребёнок 2017-05-05: «Как поддерживать друг друга?»
- Коллеги, Рыбы + Телец, 2026-09-09: будущие договорённости.

Исправлены найденные проблемы: семейный ответ был слишком общим; черновик прогноза содержал канцелярит и советы вместо возможных событий; поздний вариант добавлял ненужное деление дня на части. Добавлены возрастной контекст, запрет возлагать взрослые обязанности на ребёнка, исправление черновика по замечаниям, проверки команд и детализации времени. Версия кеша: pair-future-v4-age-aware-plain.

Premium-guard проверен отдельно: 403 до обращения к базе и модели. `git diff --check` пройден на изменённых tracked-компонентах. Полный build/test suite не запускался.

Границы доказательства: проверены получение ответа, формат, смысловое соответствие вопросу и семейному контексту. Это не подтверждение будущих событий, не проверка опубликованного API и не доказательство научной достоверности астрологии. Нативный swisseph-v2 недоступен в данном Windows runtime; тест будущей даты использовал настоящий Swiss Ephemeris через локальный Python bridge и существующие файлы ephe. Рабочий Node runtime не заменялся. UI/API/auth/cache/полные две натальные карты end-to-end не проверялись.

Повторный явный запуск: `node --import tsx scripts/nebo-pair-reading-samples.ts`. Для Windows bridge задаются NEBO_PREVIEW_PYTHON и PYTHONPATH; используемый локальный пакет pysweph 2.10.3.6 установлен отдельно в .codex/tmp/nebo-pair-check-python312, не в зависимости приложения.
