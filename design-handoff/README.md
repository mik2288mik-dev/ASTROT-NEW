# NEBO: работа из облачной сессии

Здесь всё, что было сделано в облаке и не лежит ни в коде приложения, ни на холсте.

- Холст с макетом всего приложения: https://claude.ai/artifact/BkzgAAx2CUdMH2VDkCYgQj (версия 45). Главный источник правды по дизайну.
- `prompts/NEBO-промпты-все.md`: все промпты картинок (таро, темы дня, кошка, Стрелец, 12 животных китайского гороскопа). `build.py` собирает этот файл.
- `mockup/project/`: локальная копия файлов холста (`Main.dc.html` — всё приложение, `canvas.json` — раскладка досок). Копия неполная: часть досок есть только на холсте.
- `mockup/tools/`: патчи `patch_*.py`, по которым менялся `Main.dc.html`, данные тестов и эзотерики (`tests_data.py`, `eso_data.py`), проверки: `serve.js` (локальный просмотр на порту 8770), `shot.js` (снимки досок), `smoke2.js` (ошибки в консоли).
- `media/`: видео Стрельца и дождя по стеклу с исходниками и скриптами рендера, скрипты постера «Небо в день рождения».

Код приложения: каталог товаров RuStore в `lib/rustoreProductCatalog.ts`, ветка `main-nnxrf7`, черновой PR #340. В main не сливать, пока не проверена совместимость со старой версией.

Решено: вход с небом, совместимость вариант Б, кнопки «Ночное небо», слово «бесплатно» нигде не пишем, 3 подписки и 9 разовых товаров.
