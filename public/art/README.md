# Art slots for LUMIA v2

Drop PNG/WebP here, then set paths in `lib/lzArtAssets.ts`:

| File (example)        | Slot in code      |
|-----------------------|-------------------|
| home-horoscope.png    | homeHoroscope     |
| home-natal.png        | homeNatal         |
| home-union.png        | homeUnion         |
| reader-hero.png       | readerHero        |
| magazine-cover.png    | magazineCover     |
| union-landing.png     | unionLanding      |

Example: `homeHoroscope: '/art/home-horoscope.png'`
