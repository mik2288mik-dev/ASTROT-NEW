# Forecast illustrations

Nine generated NEBO illustrations: day (glass sun, paper birds, crystal blossom), week (moon mobile, sky arch, glass wave), month (planetarium, prism, celestial compass).

Landscape 3:2, pale ivory empty left side for reading, frosted glass and porcelain subjects on the right. No text, furniture or coffee. The rejected overlapping rings are not used.

Each period rotates through its three images using the calendar date, ISO week or calendar month. CSS adds gentle motion and respects reduced-motion settings.
